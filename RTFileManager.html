02 Essential File Browser Concepts

Crucial behaviors that often confuse photographers migrating from Lightroom or Capture One.

Direct Folder Browsing (No Import)

RawTherapee does not use a database or require an "Import" step. Simply use the left-hand folder tree to click any directory on your drive or memory card. Subfolders can also be displayed recursively in newer versions (5.11+).

Why Thumbnails Change Color

Unedited raw files initially show the embedded camera JPEG as their thumbnail. The moment you open a photo in the Editor or apply a profile, RawTherapee "cooks" the actual raw sensor data using your default profile—updating the thumbnail and adding a green checkmark.

100% Non-Destructive (.pp3)

RawTherapee never modifies your original raw file. Every adjustment, rating, and color label is written to a lightweight plain-text sidecar file (image.raw.pp3) right next to your photo.

The 100% "Inspect" Tab

Need to cull blurry shots fast? Switch the right-hand panel from Filter to Inspect. Hovering your mouse over any thumbnail instantly displays a 1:1 (100%) preview of the largest embedded JPEG without waiting for full raw demosaicing.

Safe Two-Stage Trash Bin

Pressing Delete or clicking a thumbnail's trash icon does not erase the file from your disk. It tags it for RawTherapee's internal trash filter (Ctrl+T to view), letting you review before permanently deleting.

Fast Export vs. Batch Queue

The right panel features a Fast Export tab. Beware: Fast Export bypasses quality-critical pipeline tools (like high-precision demosaicing and noise reduction) for speed. Only use it for quick contact sheets—use the Queue (Ctrl+B) for final images!

Power User Workflow

Batch Editing & Profile Sync

Select multiple images in the File Browser using Shift+Click (range) or Ctrl+Click (individual). RawTherapee gives you two distinct ways to batch-edit from the File Browser:

1. Copy & Paste Partial Profiles

Copy settings from a hero image (Ctrl+C), then right-click target photos and choose Processing Profile Operations > Paste - partial (Shift+Ctrl+V) to select exact modules (e.g., White Balance & Exposure only).

2. Live Batch Edit Tab (Sync)

Open the Batch Edit tab on the right panel while multiple thumbnails are selected. Any slider you move (like enabling Lens Correction or Resizing) updates all selected photos simultaneously.

03 File Browser Cheat Sheet

Speed up your culling and navigation workflow with these built-in shortcuts.

Shortcut Action Workflow Notes
Double-Click / Enter Open in Editor Loads the raw file into the Image Editor and generates a PP3 profile.
L / Alt + L Toggle Left / Right Panels Collapses the Folder Tree (L) or Filter/Inspect pane (Alt+L).
Ctrl + B Put Selection to Queue Queues all selected thumbnails for full-resolution batch export.
Ctrl + C / Shift + Ctrl + V Copy / Partial Paste Profile Copies processing parameters and lets you choose which tools to paste.
Delete / Ctrl + T Move to Trash / View Trash Marks files as deleted inside RT without erasing them from your drive.
F2 Rename File(s) Prompts rename dialog for each selected thumbnail.
Ctrl + F5 Reveal in OS File Explorer Opens Finder/Explorer directly to the selected raw file's folder.
